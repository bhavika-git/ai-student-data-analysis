# AI Usage and Student Academic Performance Analysis

Analyzed a dataset of 50,000 students to explore relationships between AI usage, burnout risk, and academic performance.

# Key Insights
- Students with high burnout use ~15hrs of AI/week VS ~4.6hrs for low burnout.
- STEM students have the highest average GPA(3.36).
- Students with the highest level of exam anxiety show a sharp decline in their average post-semester GPA. 

# Tools Used
- Python, Pandas, Matplotlib
- Google Colab

# Dataset
AI usage and Student Academic Performance - Kaggle
